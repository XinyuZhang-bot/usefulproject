================================================================================
  AutoPowerPro 使用说明
  定时开关机  +  每 N 分钟自动重启        （便携版 / 免安装 / 绿色）
================================================================================

【一、这套东西能干什么】

  只有两个功能，都很安全，不会把电脑"关死"：

    1) 定时开关机        每天 / 仅工作日 / 自定义星期，到点关机 + 到点唤醒
    2) 每 N 分钟自动重启  纯软件循环重启，全程不断电

  适用系统：Windows 8 / 8.1 / 10 / 11，以及 Windows Server 2012 以上
            （需要 PowerShell 5.1；Windows 7 需要先装 WMF 5.1）

  台式机和笔记本都适配：环境体检会自动识别机型，并按机型给出对应的提醒
  和处理（详见第十节）。


【二、文件清单】

    启动-自动开关机.cmd    <- 双击这个（会自动申请管理员权限）
    AutoPowerPro.ps1       <- 主程序，不要单独双击，也不需要修改
    使用说明.txt           <- 就是本文件

    ★ 三个文件必须放在同一个文件夹里，不能拆开、不能只拷其中一个。


【三、怎么用（3 步）】

    1. 把整个文件夹拷到目标电脑（直接在 U 盘里运行也可以）；
    2. 双击「启动-自动开关机.cmd」；
    3. UAC 窗口点「是」，然后按菜单提示操作。

    如果 UAC 没弹出来 / 提示没有权限：
        右键「启动-自动开关机.cmd」-> 以管理员身份运行。

    任何时候输入  q  都可以取消当前操作、退回到上一步；
    主菜单按  0  退出。

    ----------------------------------------------------------------------
    启动后会先显示一张「环境体检」面板
    ----------------------------------------------------------------------
    打开就能看到本机的关键信息，不用去别处查：

        机型        台式机 / 笔记本  + 品牌型号
        供电        交流电 / 正在使用电池（带电量百分比）
        系统        Windows 版本与内部版本号
        权限        是否已提权
        休眠        可用 / 未启用（选「休眠」时工具会自动尝试打开）
        唤醒定时器   接电源 允许/禁止      用电池 允许/禁止
        定时开关机   已安装-休眠 / 未安装
        循环重启     已安装-每30分钟 / 未安装

    面板下面还会按机型给出针对性提醒：
        笔记本 -> 插电源、合盖设置、电池下唤醒定时器可能被限制
        台式机 -> 休眠默认关闭、待机时别断插排

    主菜单底部也常驻一行机型摘要，例如：
        本机：笔记本 · 已接电源 · 休眠未启用

    ★ 检测是"多级兜底"的：先用 WMI，取不到就用 .NET，再取不到就读注册表。
      所以在精简系统、或被安全软件限制 WMI 的机器上也不会显示成空白。


【四、功能 1：定时开关机】

  菜单选 [1]，跟着 4 步走（每一步直接按回车就用方括号里的默认值）：

      第 1 步   每天几点关机？        默认 23:00
      第 2 步   每天几点开机（唤醒）？ 默认 07:30
      第 3 步   到点后怎么"关"？      默认 1 = 休眠
                  1) 休眠  真正断电、状态完整保留、唤醒最可靠     <- 推荐
                  2) 睡眠  唤醒只要 1~2 秒，但内存一直供电耗电
                  3) 关机  最省电，但必须靠 BIOS 定时开机才能自己起来
      第 4 步   哪几天生效？          默认 2 = 仅工作日
                  1) 每天     2) 仅工作日（周一~周五）     3) 自定义星期

  时间支持这几种写法：23:00 / 7:30 / 2300 / 23（只写小时=整点）

  最后会给你一张确认卡片，核对没问题再按 Y。卡片里会直接算出"首次触发"
  是今天还是明天 —— 如果你填的时间今天已经过了，第一次触发会顺延到明天。

  ----------------------------------------------------------------------
  ★ 关机方式怎么选（这段最重要，请看完）
  ----------------------------------------------------------------------
    推荐「休眠」。原因：

      休眠    真正切断电源、内存内容写进硬盘、下次开机原样恢复，
              而且软件一定能唤醒它。台式机和笔记本都适用。

      睡眠    唤醒最快，但内存一直在供电。笔记本合盖拔掉电源会掉电丢数据。

      关机    最省电，但"关了就起不来了" —— 因为完全关机之后，
              Windows 里没有任何东西在运行，软件不可能自己把自己叫醒。

  ----------------------------------------------------------------------
  ★ "自动开机"到底能做到什么程度
  ----------------------------------------------------------------------
    从「休眠 / 睡眠」唤醒   ->  软件做得到。本工具已经自动帮你：
                                · 打开电源方案里的"允许唤醒定时器"（接电源+用电池都开）
                                · 给唤醒任务勾上"唤醒计算机运行此任务"

    从「完全关机」开机     ->  软件做不到！只有两条路：
                                ① BIOS 的 RTC 定时开机
                                   （只能设"每天几点"，没有别的选项）
                                ② 通电自动开机（换电源 / 按插座开关触发）
                              所以如果你在第 3 步选了「关机」，
                              必须自己去 BIOS 把 RTC 定时开机设上，否则不会自己起来。

  ----------------------------------------------------------------------
  测试小技巧
  ----------------------------------------------------------------------
    第一次别直接设 23:00。先填一个 3 分钟之后的时间，验证一下能不能正常
    关机 / 唤醒，确认没问题再改成真正要用的时间。

    另外注意：本工具的"关机"和"唤醒"共用同一套生效日。
    如果选了「仅工作日」，周五晚上关机后，下一次自动开机是周一早上，
    整个周末电脑都是关着的 —— 这通常不是你想要的，请改用「每天」。

  装完之后会显示一张结果卡片：装了什么、下次什么时候生效、怎么撤销。


【五、功能 2：每 N 分钟自动重启】

  菜单选 [2]，跟着 2 步走：

      第 1 步   每隔多少分钟重启一次？   默认 30   （范围 5 ~ 1439）
      第 2 步   重启前留多少秒缓冲？     默认 60   （范围 5 ~ 600）

  ★ 下限定在 5 是刻意的：间隔和缓冲太小会让机器"刚开机就被重启"，
    基本没法使用；缓冲 0 秒等于不给你任何取消的机会。

  原理：创建一个计划任务，从"现在 + N 分钟"开始，每 N 分钟重复一次
        （持续时间：无限期），执行
            shutdown.exe /r /t <缓冲秒数> /c "AutoPowerPro cycle restart"

  效果：电脑每次开机大约 N 分钟后就自动重启一次 —— 不停机、不断电，
        但操作系统和所有程序会完整重新加载一遍。

  常用操作：
    · 临时取消本次重启    命令行执行   shutdown /a
    · 立刻停掉整个循环    回主菜单选 [5] 卸载，
                          或管理员命令行：schtasks /End /TN AutoPowerPro_CycleRestart

  ----------------------------------------------------------------------
  两个"刻意不做"的设计（很重要）
  ----------------------------------------------------------------------
    · 不补跑：如果某次重启因为机器关机/休眠而错过，它不会在下次开机时补上。
      否则每次开机都会被补跑一次 -> 开机即重启 -> 死循环。
    · 不唤醒：机器已经休眠/睡眠时，循环重启不会把它叫醒（避免半夜被折腾）。

  ★ 这个方案不会给电脑断电。如果你要的是"让机器彻底冷启动"，
    那属于硬件层面的事，软件做不到。

  ★ 本版修掉了一个老问题：以前用 schtasks /Create 建任务，Windows 默认给它的
    设置是"只在交流电源下运行"，笔记本拔掉电源后循环重启根本不会触发。
    现在改用 Register-ScheduledTask，并显式打开电池策略，笔记本也能正常工作。


【六、查看状态 / 卸载】

  主菜单 [3]  查看当前状态（只读，不做任何修改）
      最上面先是本机概况（机型 / 供电 / 休眠 / 唤醒定时器策略），
      然后每个任务列出：执行动作 / 下次运行 / 上次运行 / 是否勾了唤醒运行，
      并附带一份"唤醒能力自检"：
          - 系统当前实际武装的唤醒定时器（powercfg /waketimers）
          - 唤醒日志（每次定时唤醒都会记一笔时间，最近 5 条）
          - 休眠在本机是否可用（powercfg /a）

  主菜单 [4]  运行记录
      什么时候关机 / 重启 / 唤醒了 —— 完整说明见下一节【七】。

  主菜单 [5]  卸载
      会先列出将要删除的任务让你确认，然后逐个删除并回报结果
      （删除失败的会单独标红，不会假装成功），再问你要不要
      一并清理数据目录 C:\ProgramData\AutoPowerPro（只存唤醒日志）。
      卸载完同样有结果卡片，并说明哪些系统设置没有被回滚。

  本工具创建的任务一共 3 个（也可以用 taskschd.msc 手动删）：
      AutoPowerPro_ScheduledOff     定时关机 / 休眠 / 睡眠
      AutoPowerPro_ScheduledOn      定时唤醒
      AutoPowerPro_CycleRestart     每 N 分钟自动重启


【七、运行记录（什么时间关机 / 重启 / 唤醒了）】

  主菜单 [4]「运行记录」。这是本版新增的功能，回答三个问题：

      什么时候重启了机器？
      什么时候执行了关机 / 休眠 / 睡眠？
      什么时候被唤醒了？

  记录来自两个来源，合并后按时间倒序显示（最近 40 条）：

    · 来源「本工具」= 计划任务被触发的时刻
          进入休眠（定时任务触发）
          进入睡眠（定时任务触发）
          执行关机（定时任务触发）
          定时唤醒触发
          循环重启触发
        文件位置：C:\ProgramData\AutoPowerPro\events.log

    · 来源「系统」= Windows 事件日志里的真实电源事件（权威来源）
          发起关机/重启（xxx.exe）  连手动关机、Windows 更新重启都算
          系统启动完成 / 系统正常关机 / 异常关机（断电或死机）
          进入睡眠 / 从睡眠唤醒
          进入、退出新式待机（Modern Standby，较新的笔记本常见）
          从睡眠唤醒（含唤醒源）
          内核意外断电重启
        来源「异常」的事件会标红显示。

  面板下面还有汇总：今天唤醒几次、关机类几次、重启几次、
  系统电源事件几条、最近一次唤醒是什么时候。

  两条要点：
    · 「本工具」记的是"任务被触发"的时刻。循环重启用的是关机前缓冲，
      所以它会比真正重启早一个缓冲秒数（默认 60 秒）—— 在记录里会成对出现。
    · 只有「休眠 / 睡眠」才能被软件唤醒；选了「关机」的话，
      系统里不会出现唤醒记录（因为它根本没睡，是被关掉了）。

  命令行也可以直接看：   AutoPowerPro.ps1 -Log

【八、命令行参数（可选，给喜欢命令行的人）】

    管理员 PowerShell 里执行：

        .\AutoPowerPro.ps1 -Status       只查看状态（只读，不改系统）
        .\AutoPowerPro.ps1 -Log          只查看运行记录（关机/重启/唤醒历史）
        .\AutoPowerPro.ps1 -Uninstall    卸载全部计划任务
        .\AutoPowerPro.ps1 -Help         显示帮助

    如果提示"在此系统上禁止运行脚本"，换成这种写法：

        powershell -NoProfile -ExecutionPolicy Bypass -File ".\AutoPowerPro.ps1" -Status


【九、常见问题】

    Q1  双击 .cmd 一闪就没了？
        -> 多半是 .ps1 不在同一个文件夹里，或者被杀毒软件拦截了。
           用管理员身份运行一次，就能看到红字错误提示。

    Q2  提示"需要 PowerShell 5.1 或更高版本"
        -> 系统是 Windows 7 或更老，需要先安装 Windows Management Framework 5.1。

    Q3  菜单里的中文是乱码？
        -> 说明 AutoPowerPro.ps1 的编码被改坏了。
           必须保持 UTF-8 with BOM（用记事本另存为时选 "UTF-8"）。
           如果传输过程中丢了 BOM，重新从原始压缩包解压一份。

    Q4  设了"休眠"但到点没进入休眠
        -> 说明系统里休眠不可用：可能是精简版系统 / 被组策略禁用 / 系统盘空间不足。
           管理员命令行执行  powercfg /hibernate on  看报什么错；
           或者干脆改用"睡眠"。

    Q5  到点了没有关机
        -> 打开"任务计划程序"，看 AutoPowerPro_ScheduledOff 在不在、状态是不是"就绪"。
           如果关机时间填的是今天已经过去的时间，第一次触发会顺延到明天
           （确认卡片里会直接写出来）。
           笔记本还要确认没被"电池"策略拦住（本工具已设 AllowStartIfOnBatteries = True）。

    Q6  关机了，但第二天没有自动开机
        -> 只有「休眠 / 睡眠」才能被软件唤醒。
           如果你选的是「关机」，必须去 BIOS 开 RTC 定时开机，否则它永远不会自己起来。

    Q7  想彻底清理干净
        -> 主菜单选 [5] 卸载；再手动删掉本文件夹即可。

    Q8  笔记本拔掉电源后，循环重启不触发了？
        -> 本版已经修掉（改用 Register-ScheduledTask 并显式打开电池策略）。
           如果仍然不触发，打开 taskschd.msc 找到 AutoPowerPro_CycleRestart，
           在「条件」页确认"只有在计算机使用交流电源时才启动此任务"没有被勾上。

    Q9  循环重启会不会半夜把休眠中的电脑叫醒？
        -> 不会。循环重启任务没有勾"唤醒计算机运行此任务"，
           机器睡着后它就不再触发（有意设计）。

    Q10 环境体检里的"机型/系统"显示不出来？
        -> 该机器可能禁用了 WMI。本工具已经做了多级兜底（WMI -> .NET -> 注册表），
           正常情况下不会空白；如果确实空白，也不影响开关机功能。


【十、台式机 / 笔记本适配】

    ----------------------------------------------------------------------
    台式机
    ----------------------------------------------------------------------
    · 休眠默认大多是关闭的（没有 hiberfil.sys 文件）。
      选「休眠」时，工具会自动执行 powercfg /hibernate on 打开它，
      代价是系统盘会生成一个约等于内存大小的 hiberfil.sys
      （8GB 内存约 6~7GB 空间），装之前请确认系统盘够用。
    · 待机时不要断插排、不要关电源开关 —— 否则唤醒定时器失效，机器不会自己醒。
    · 没有电池，所以"电池策略"这项对它没有影响。

    ----------------------------------------------------------------------
    笔记本
    ----------------------------------------------------------------------
    · 三个任务的电池策略都已显式打开（允许用电池时启动、不因切到电池而停止）。
    · 电源方案里的"允许唤醒定时器"会同时打开「接电源」和「用电池」两项。
    · 仍然建议：做整夜唤醒测试、或使用循环重启时，插着电源。
      部分机型在电池供电下会自行限制唤醒定时器（厂商策略，软件改不了）。
    · 「合盖」动作会覆盖本计划：如果合盖设为"睡眠/关机"，
      那么合盖之后唤醒任务不会执行。请到
      控制面板 -> 电源选项 -> 选择关闭盖子的功能 里确认。
    · 环境体检面板会显示当前是"交流电"还是"使用电池"，以及电量百分比。

    ----------------------------------------------------------------------
    两种机型都适用的验证方法
    ----------------------------------------------------------------------
    第一次别直接设 23:00。先填一个 3 分钟之后的时间，验证能否正常关机/唤醒，
    确认没问题再改成真正要用的时间。休眠会完整保留状态，即使没醒也不会丢数据
    （按一下电源键即可恢复）。


【十一、安全提醒】

    · 定时关机用的是 shutdown /s /t 120（只有第 3 步选「关机」时才会用到），
      有 120 秒缓冲。这 120 秒内在命令行执行  shutdown /a  可以取消。

    · 「每 N 分钟自动重启」会让工作频繁中断。装之前先保存好文档、
      关掉没必要的程序，避免数据丢失。它同样有缓冲期（默认 60 秒），
      期间执行  shutdown /a  可以取消本次重启。

    · 「定时开关机」和「每 N 分钟自动重启」不建议同时开启：
      两者会互相打断（刚休眠就被叫起来重启之类）。
      如果检测到冲突，菜单会明确问你一次，不会再默默装上。

    · 所有计划任务都以 SYSTEM 身份运行，不依赖登录密码，
      所以就算你设置了开机自动登录、或者用微软账号登录，也照样生效。

    · 卸载只删除本工具创建的 3 个计划任务，不会动系统里其它任何任务；
      "允许唤醒定时器"这个电源设置会保持原样，不做还原。
      如果之前打开过休眠，hiberfil.sys 仍会保留；想彻底关掉可执行
      powercfg /hibernate off
