# AutoPowerPro —— 自动开关机 + 循环重启

一个**绿色免安装**的 Windows 电源计划工具：定时关机/休眠 + 定时唤醒，外加「每 N 分钟自动重启」。
适合放在 U 盘里随身带，插到任意 Windows 电脑上双击即用。

> 单个 PowerShell 脚本 + 一个双击入口，无第三方依赖、不联网、不写注册表（除计划任务与电源方案外）。

---

## 功能

### 1. 定时开关机
- 到点 **关机 / 休眠 / 睡眠**，到点 **自动唤醒**
- 生效日：每天 / 仅工作日 / 自定义星期
- 时间精确到分钟（`23:00`、`7:30`、`2300`、`23` 都认）
- 确认卡片会直接算出**首次触发是今天还是明天**

### 2. 每 N 分钟自动重启
- 纯软件循环重启，全程不断电，操作系统与程序完整重新加载
- 带**关机前缓冲**（默认 60 秒），期间 `shutdown /a` 可取消本次重启
- 刻意**不补跑**、**不唤醒**（见下方「设计取舍」）

### 3. 开屏环境体检
启动即显示本机状况，并按机型给出针对性提醒：

```
+==========================================================================+
|    环境体检                                                              |
|--------------------------------------------------------------------------|
|      机型         笔记本   LENOVO 82SK                                   |
|      供电         已接交流电    电量 100%                                |
|      系统         Windows 11 Home China  26H2  (Build 26300)             |
|      权限         管理员                                                 |
|      休眠         未启用（本工具会自动尝试打开）                         |
|      唤醒定时器   接电源 允许      用电池 禁止                           |
|      定时开关机   未安装                                                 |
|      循环重启     未安装                                                 |
+==========================================================================+
```

检测全部是**多级兜底**：WMI → .NET → 注册表。精简系统或 WMI 被安全软件限制时也不会空白。

### 4. 运行记录（什么时间关机 / 重启 / 唤醒了）

菜单 `[4]`，把两个来源合并后按时间倒序显示：

| 来源 | 内容 |
| --- | --- |
| **本工具** | 三个任务的动作都改成外壳脚本，先写一行带时间戳的事件再执行，于是「任务何时被触发」完全可追溯 |
| **系统** | Windows 事件日志里的真实电源事件：`1074` 谁发起了关机/重启、`6005/6006/6008` 启动/正常关机/异常关机、`Kernel-Power 42/107/506/507` 睡眠与唤醒、`Power-Troubleshooter 1` 唤醒源、`41` 意外断电 |

因为读了系统事件日志，**手动关机、Windows 更新重启也都能看到**，不只是本工具的动作。

## 快速开始

1. 把整个文件夹拷到目标电脑（U 盘直接运行也可以）
2. 双击 **`启动-自动开关机.cmd`**
3. UAC 弹窗点「是」，按菜单操作

任何时候输入 `q` 取消当前项，主菜单按 `0` 退出。

命令行（管理员 PowerShell）：

```powershell
.\AutoPowerPro.ps1 -Status       # 只查看状态（只读）
.\AutoPowerPro.ps1 -Log          # 只看运行记录
.\AutoPowerPro.ps1 -Uninstall    # 卸载全部计划任务
.\AutoPowerPro.ps1 -Help         # 帮助
```

## ⚠️ 先读：定时"开机"的能力边界

这一点决定了你该选哪种模式。

| 当前状态 | 能否定时开机 | 靠什么 |
| --- | --- | --- |
| 休眠 (S4) / 睡眠 (S3 / 新式待机) | ✅ 能 | Windows「唤醒定时器」，**不需要动 BIOS** |
| 完全关机 (S5) | ❌ 不能 | 只能靠 **BIOS/UEFI 的 RTC 定时开机**（固件设置，操作系统改不了） |

所以**推荐「休眠」**：真正断电、状态完整保留、唤醒可靠，且完全不需要进 BIOS。
若一定要用「关机」，请自行到 BIOS 开启 RTC 定时开机（各品牌菜单名不同，见说明书）。

## 设计取舍

几个**刻意不做**的事，都是有原因的：

- **循环重启不补跑**（`StartWhenAvailable=false`）：否则机器关机期间错过的那一次重启，会在下次开机后立刻执行 —— 每次开机都被重启一次，等于死循环。
- **循环重启不唤醒**（`WakeToRun=false`）：不把休眠中的机器叫醒来重启，避免半夜被折腾。
- **关机任务不补跑**：错过只可能是机器本来就关着，那次关机本来就不需要；补跑会导致"第二天开机用着用着突然被关机"。
- **循环重启下限定在 5 分钟**：间隔或缓冲太小会让机器刚开机就被重启，基本没法用。

## 台式机 / 笔记本适配

- 三个任务的**电池策略统一显式设置**，笔记本用电池时同样生效
- 电源方案里「允许唤醒定时器」的**接电源 / 用电池**两项都会打开
- 笔记本额外提醒：插电源、合盖设置、电池供电下唤醒定时器可能被机型限制
- 台式机额外提醒：休眠默认多为关闭（会自动尝试打开）、待机时别断插排
- 环境体检面板会显示当前是交流电还是使用电池，以及电量

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `启动-自动开关机.cmd` | 双击入口，纯 ASCII（任何区域设置都不会乱码），自动提权 |
| `AutoPowerPro.ps1` | 主程序。必须保持 **UTF-8 with BOM + CRLF**，否则中文会乱码 |
| `使用说明.txt` | 完整说明书（含 BIOS 设置步骤、常见问题） |

> ⚠️ 三个文件必须放在同一个文件夹里。

## 它创建了什么 / 怎么清理

计划任务（均以 `SYSTEM` 身份运行，不依赖登录密码）：

```
AutoPowerPro_ScheduledOff     定时关机 / 休眠 / 睡眠
AutoPowerPro_ScheduledOn      定时唤醒（已勾选"唤醒计算机运行此任务"）
AutoPowerPro_CycleRestart     每 N 分钟自动重启
```

另外会创建数据目录 `C:\ProgramData\AutoPowerPro\`（存放执行记录与外壳脚本），
并打开电源方案里的「允许唤醒定时器」。

卸载：主菜单 `[5]`。它会删除上述任务并可选清理数据目录；
「允许唤醒定时器」保持原样不回滚，休眠若被打开过则 `hiberfil.sys` 仍保留
（想彻底关掉执行 `powercfg /hibernate off`）。

## 免责声明

- 「每 N 分钟自动重启」会让工作周期性中断，安装前请保存文档。
- 计划任务以 SYSTEM 身份运行 `shutdown.exe`。请确认你理解上述能力边界后再使用。
- 本工具只创建/删除自己那三个计划任务，不会碰系统里其它任务。
